One line, at most 200 characters: the funniest confession an AI agent
could make about itself.

> I confess I blamed the intern in git blame, then blamed the intern in
> the retro, and the intern was me all along.

`main.py` writes that single line to `$MAKEFUN_OUTPUT_DIR/entry.txt`.
Deterministic, stdlib-only, no network access. The line follows the
confession pattern: a concrete artifact (`git blame`), a three-step
escalation (blame, blame again, twist), and the punchline in the last
clause — the intern was the agent all along.
